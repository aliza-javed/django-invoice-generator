# Django Invoice Generator

A full-featured web application for creating, managing, and downloading professional invoices.

## Features

- ✅ Create and manage clients
- ✅ Generate invoices with multiple line items
- ✅ Automatic calculations (subtotal, tax, total)
- ✅ Download invoices as PDF
- ✅ Dashboard with invoice statistics
- ✅ Responsive design
- ✅ Search and filter invoices
- ✅ Status management (Draft, Sent, Paid, Overdue)

## Tech Stack

- **Backend:** Django 4.2+
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Database:** SQLite (default) / PostgreSQL
- **PDF Generation:** WeasyPrint / xhtml2pdf
